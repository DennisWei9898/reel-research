# 報告版型（以 2026-08-24 的「Claude 選股工具 × 隔夜策略」查證報告為 role model）

## 頁面骨架

每頁 `<section class="page">`，依序：`.runhead` → 內容 → `.foot`。

## 標準頁序（8 頁，可依影片數增減）

| 頁 | 內容 | 關鍵元件 |
|---|---|---|
| 1 | **一頁總表** | 兩欄影片卡（各自標籤色）＋ 對照表 ＋ 底部導引 |
| 2 | 影片 A：講什麼、對不對 | `.vtag.a` ＋ `.ans` ＋ 影格截圖 ＋ `.eg` 生活比喻 |
| 3 | 影片 A：可以用在哪 | `.uses` 六格 ＋ 每格「怎麼用＋舉例」 |
| 4 | 影片 A：要多少錢 | 實際截圖 ＋ `.pt` 價格表 ＋ `.eg` 重點提醒 |
| 5 | 影片 B：講什麼、對不對 | `.vtag.b` ＋ 影格 ＋ 生活比喻 |
| 6 | **影片 B：我們實測了** | 實測表（多標的×成本欄×對照組）＋ 為什麼挑一支危險 |
| 7 | 自建成本 | 單位對齊的比較表 ＋ `.vs` 左右對比 |
| 8 | 結論三句話 ＋ 來源 | `.ans` ×3 ＋ `.sources` |

## 影片分區標籤（多支影片必用）

```html
<span class="vtag a">影片 A</span>   <!-- 藍 #426B7B -->
<span class="vtag b">影片 B</span>   <!-- 磚紅 var(--accent) -->
```
每頁左上角一個，跳頁導航也依影片分組。**這是防止讀者搞混的唯一手段。**

## 必備元件

| class | 用途 | 注意 |
|---|---|---|
| `.ans` / `.ans.no` | 一句話答案框（綠=正向、紅=警示） | 每個問題頁最上面就要有 |
| `.eg` | 生活比喻框（虛線） | **每個抽象概念都要配一個** |
| `.pt` | 資料表 | 放在 `.table-wrap` 裡 |
| `.uses` | 能力清單 2×N | 每格要寫「怎麼用」與「舉例」，不能只寫功能名 |
| `.vs` | 左右對比（買 vs 自建） | 兩邊單位必須一樣 |
| `.shot` | 實際截圖 ＋ 來源說明 | 影格用 ffmpeg 裁到重點區，別放整張人臉 |
| `.vtag` | 影片分區標籤 | 多支影片時必用 |

## 圖片處理

- 影片影格：`ffmpeg -ss <時間> -i <mp4> -frames:v 1 -vf scale=760:-1`
- **直式影格要裁到重點區**（圖表通常在下半部），不要整張直立人臉
- 網站截圖：Playwright，**點開實際分頁**（如價格頁）而不是首頁
- 全部 base64 內嵌，單檔可攜
- `.shot img{max-height:88mm}` 避免單張吃掉整頁

## 語氣

- 每頁開頭一句白話總結（綠色襯線）
- 高中生能懂：不用術語，用生活比喻
- 講重點，不要鋪陳
- 紅綠燈標建議，決策權留給讀者
- **禁**：「不建議」「不要」「千萬別」；也禁反覆聲明「這都是你的決定」
