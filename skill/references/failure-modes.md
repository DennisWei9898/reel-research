# 十大失效模式（逐條主張過篩用）

> 核心立場：**抓造假是入門，真正要抓的是「數字全對、算式全對、但結論是錯的」。**
> 實測樣本：8 條可查主張裡，造假 0 條、呈現誤導 3 條、出處蒸發 1 條。
> **只查造假的話，這類內容 100% 過關。**

## FM-1 拆分幻覺
把一個總量拆成兩半，只秀好的那半。複利乘幾千次後兩邊都變天文數字。
**抓法**：問「兩半乘回去等於什麼？」若 `(1+A)×(1+B)-1 = 原本就知道的總報酬`，A 不是獨立策略。
**實例**：隔夜報酬 +1.38 億% / 日內 −99.92%，乘回去就是那檔股票的真實漲跌。

## FM-2 選樣偏誤
樣本是事後挑的；或反過來，刻意挑已歸零的極端值把百分比撐大。
**抓法**：**圖裡每一個標的都去查現在還在不在市面上交易。**
**實例**：某圖含房利美、Rite Aid、Yellow Corp——真實總報酬≈−100%，卻標「隔夜 +2482 萬%」。

## FM-3 單邊敘事
只講「錯過最好的 N 天很慘」，不講「同時也避開了最壞的 N 天」。
**抓法**：主動去搜對稱的另一半數據。
**實例**：BofA 數據顯示「同時避開最好和最壞」反而贏過買著不動。

## FM-4 成本消失
手續費、買賣價差、借券費、滑價、稅，一項都沒算。
**抓法**：算「交易頻率 × 單次成本」。高頻策略這項通常直接歸零。

## FM-5 量級偷換
學界公認效應是年化個位數%，圖上寫「+1.38 億%」。
**抓法**：問「這個領域公認的量級是多少？」**差三個數量級以上就是紅旗**，不用細看方法論。

## FM-6 出處蒸發
「一篇研究發現…」但不說哪一篇。
**抓法**：用**精確數字**去搜。搜不到一手來源 → 標「查無實據」，**不是「應該是真的」**。

## FM-7 權威借用
引真學者、真理論（諾貝爾獎得主、聯準會報告）包裝一個論證跳躍的結論。
**抓法**：問「那個理論真的支持這個結論嗎？」**學術背書是真的 ≠ 這個推論是真的。**

## FM-8 座標失真
log 軸、Y 軸不從 0 開始、雙軸刻意對齊、區間截斷。
**抓法**：看軸——從哪開始？是不是 log？區間為什麼選這段？

## FM-9 時效腐爛
效應曾經成立但已被套利消失／規則已改／工具已下架／API 已關。
**抓法**：專搜 `<topic> 最近年份`、`<topic> still works`、`<topic> decay`。

## FM-10 張冠李戴
標「Source: 某知名機構」但該機構官網查無此圖，或日期範圍被改過。
**抓法**：去**官網原始頁面**找原圖比對標題與期間。

## 判定與信心

| 判定 | 意思 |
|---|---|
| `屬實` | 數字對、呈現公允、可獨立驗證 |
| `部分屬實` | 數字對但**命中一個以上 FM**——最常見的判定 |
| `有問題` | 數字對但結論不成立 |
| `查無實據` | 找不到一手來源。**不等於造假，但也不等於可信** |
| `無法查證` | 需要非公開資料才能判 |

**硬規則：`查無實據` 不得升級成 `屬實`。** 「聽起來合理」不是證據。

## 公平起見（必填區塊）

報告必須列出這個內容**做對的地方**。原因有二：
1. 沒有這塊，報告變成獵巫，可信度反而下降
2. **「創作者有沒有主動揭露自己的弱點」是最省力的可信度分類器**——
   在看懂技術細節之前就能判斷，值得單獨教給讀者
